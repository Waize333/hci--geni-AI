# Menu lab

The `/lab` route previews the six study layouts without creating a participant session or writing study events to the server. `/lab?menu=B` opens a chosen layout; unsupported menu IDs use A.

The guide describes the current layout and expands to compare all six. State context changes the preview label only. Colour mapping changes department colours. Restart preview clears the local event history and returns the selected layout to its first level while preserving the selected context and colour mapping.

Researcher guidance and controls remain outside the fixed 1800 × 720 canvas. Study menu components and their navigation behavior are shared with the experiment.
